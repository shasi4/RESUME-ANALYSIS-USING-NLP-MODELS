This study has created and tested an intelligent AI-based system for  automatically analyzing resumes and recommending candidates in order to make hiring more efficient. The system effectively analyzes unstructured resume data and generates meaningful insights by combining NLP-based preprocessing, NER-driven information extraction, ATS-basedscoring, and RAG-based recommendation modules.

\vspace{6pt}
\noindent The analysis of the proposed framework leads to the fol
lowing key observations:
    Using NLP and NER techniques, the system successfully pulls out useful information like skills, education, and experience, which makes sure that candidate profiles arecorrect.
    The ATS-based scoring system is a reliable and organized way to rank candidates based on how well they fit the job.
    The combination of RAG makes it possible to give personalized feedback, analyze skill gaps, and makere commendations that are specific to the field, which helps candidates get ready.
     The system shows that it is more efficient by cutting down on manual work and speeding up decision-makingin hiring processes by using data.
     The modular architecture ensures scalability and adaptability across multiple domains such as Data Science,DevOps, Testing, and Web Development.
\vspace{6pt}
\noindent The proposed system is a smart and effective way to deal with modern resume screening problems. It makes both the recruiter’s job easier and the candidate’s experience better
